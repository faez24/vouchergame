API Documentation

Introduction
VocaBisnis is a game credit purchase and deposit platform for the needs of top up sales of game credits owned by partners by offering the best product prices and a varied selection of games. can be connected via API service.

Getting Started
Obtaining Secret Key & Merchant ID
You can get an Merchant ID & Secret Key by authorizing at Bisnis Vocagame with your account. Secret Key used to generate signature.

Generate Signature
To make a transaction request, you must create a signature that will be validated by the VocaBisnis system to ensure data and sender integrity when transmitted to the VocaBisnis system. On a new Transaction request, this signature is created from a combination of the Merchant ID and Endpoint.

Endpoints
/merchant
/products
/products/:productId
/products/:productId/items
/transaction/:referenceId
/transaction/:invoiceId/detail

The datas are hashed using the HMAC-SHA256 algorithm type which is locked with a Secret Key. Here is an example of creating a signature.

Example:
import { createHmac } from 'crypto';
const merchantId = "xxxx-xxx-xx-xxx-xxxxxx";
const endpoint = "/merchant";
const secretKey = "xxxxxxxxxxxxx";
const signature = createHmac('sha256', secretKey)
  .update(merchantId + endpoint)
  .digest('hex');

Callback
Callback mechanism is back-end activity that to notify merchant system once there are changes on any purchase status.
Merchant can provide the Callback URL on body payload in order. Callback URL can be activated for better merchant purchase system communication.

Verify events are sent from Bisnis Vocagame
Vocagame can optionally sign the callback events it sends to your endpoints. We do so by including a token in each event's X-Callback-Key header. This allows you to verify that the events were sent by Vocagame, not by a third party.

Method: POST
Endpoint: Provided by your request payload
Headers:
- X-Callback-Key: Get on panel dashboard

{
  "reference": "reference-id-3",
  "status": "Success", // "Processing" | "Success" | "Refunded"
  "productName": "Mobile Legend",

}

Errors
Your integration might have to deal with errors at some point when making API requests to VocaBisnis. These errors fall into a few major details:

{
  "statusCode": 401,
  "message": "Invalid Merchant",
  "error": "Unauthorized"
}

{
  "statusCode": 401,
  "message": "Invalid signature",
  "error": "Unauthorized"
}

{
  "statusCode": 404,
  "message": "User tidak ditemukan"
}

{
  "statusCode": 500,
  "message": "Internal Server Error"
}
